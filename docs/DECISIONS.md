# EchoTracker — DECISIONS

<!-- Append-only. Формат фиксирован. -->

## 2026-09-08: Публичный репозиторий-шаблон, копия на проект

**Контекст:** Нужна одна доска на проект для соло-разработки: свои задачи и ожидание заказчика. Данные проектов смешиваться не должны.

**Решение:** Public-репозиторий MIT как шаблон. Каждая копия — отдельный деплой со своей SQLite и папкой файлов. project_id в базе нет.

**Альтернативы:** Один мультитенантный сервис на все проекты; готовый SaaS.

**Trade-off:** N копий обновлять вместо одной. Лечится шаблоном: код отдельно, данные и конфиг отдельно, обновление подтягиванием шаблона.

## 2026-09-08: Тонкий React без тяжёлых библиотек

**Контекст:** Долго считался тяжёлым, но последний проект переубедил. Ванила вечнее, React продуктивнее.

**Решение:** React thin: fetch + drag&drop, без гридов и форм-библиотек. На сервер уезжает только собранный dist.

**Альтернативы:** Ванила без сборки; тяжёлый стек с гридом.

**Trade-off:** Тулчейн и обновления зависимостей вместо вечного html-файла. Выигрыш — скорость разработки и перенос опыта.

## 2026-09-08: MD-производная docx сразу в v1

**Контекст:** Docx надо и читать быстро, и скармливать автоматизации.

**Решение:** Оригинал хранится как есть. Рядом md-производная клиентской связкой mammoth + turndown: просмотр и скачивание обоих. Полный WYSIWYG не делаем.

**Альтернативы:** Только скачать; свой офисный сервер; внешний вьювер.

**Trade-off:** Потери сложного форматирования в md. Выигрыш — ноль серверных зависимостей и md для поиска и автоматизации.

## 2026-09-08: Файлы в папке, уведомления Email

**Контекст:** Файлы прикладывает любой участник. Уведомления нужны без внешних сервисов.

**Решение:** Хранилище — папка рядом с базой (порт Storage, файловый адаптер). Имена на диске uuid, отдача через API с проверкой прав. Уведомления — порт Notifier, первый адаптер Email, в письмах ссылки, не вложения.

**Альтернативы:** MinIO/S3 сразу; вложения в письма; мессенджеры.

**Trade-off:** Без MinIO нет горизонтального масштаба — он и не нужен под копию на проект. Email без пушей — достаточно для соло.
