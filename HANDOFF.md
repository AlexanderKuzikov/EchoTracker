## Контекст

- Админ создаётся сидом из .env при пустой таблице users; застрявший сид лечится сносом users при пустой доске
- Пароль admin на BikDesk-полигоне задаёт пользователь в echo/.env, в репо его нет
- Порты 8100/5174 с автоподбором; веб BikDesk-проекта уехал на 5174, CaseCore сидит на 5173 — не трогать
- ECHO_BASE дефолт /echo/, доки проекта ищутся в ../../docs от echo
- В UI капс запрещён всегда; шрифт Inter лежит в репо (OFL)
- Коммиты прямо в main, заголовок повелительный до 72 символов без точки
- BikDesk: коммит только когда попросят, сообщение = строка журнала, промежуточное с wip
